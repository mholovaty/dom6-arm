# Loader source tree

C source for the dom6 ARM64 loader.  Compiles together with the data
tables that `tools/build_loader.py` generates into `../build/loader/gen/`.

## Project layout

```
dom6-arm/
├── src/                          ← THIS DIRECTORY: loader source, committed
│   ├── README.md                 ← (you are here)
│   ├── loader_common.h           ← shared includes, typedefs, globals
│   ├── loader_main.c             ← entry point, startup orchestration
│   ├── loader_os.h               ← OS abstraction (mmap/dlopen/signal/…)
│   ├── loader_os_posix.c         ← POSIX backend (Linux)
│   ├── loader_os_win32.c         ← Win32 backend
│   ├── loader_crash.c            ← crash signal handler + symbolication
│   ├── loader_counters.h         ← SHIM_HIT macro + SHIM__* enum
│   ├── loader_counters.c         ← counter dump function, signal install
│   ├── loader_shims.c            ← mac_* ABI shims (libc, sockets, GCD…)
│   ├── loader_sdl_gl.c           ← install_sdl_redirect + install_gl_redirect
│   └── loader_win_vbo.c         ← software VBO emulation for Win opengl32
│
├── build/loader/gen/             ← GENERATED by tools/build_loader.py
│   ├── segments.inc              ← mmap target VAs + sizes per Mach-O segment
│   ├── got_bindings.inc          ← GOT / __la_symbol_ptr slot fills
│   ├── shim_table.inc            ← SHIM__* enum body + names[] + kinds[]
│   ├── shim_thunks.inc           ← per-symbol nop_X thunk definitions
│   ├── sdl_redirect.inc          ← SDL dynapi slot map + va wrappers + host_* externs
│   ├── gl_redirect.inc           ← gl/glu GOT slots + names + lib pick
│   └── entry.inc                 ← MAC_ENTRYPOINT VA
│
└── tools/build_loader.py         ← reads origin/dom6_mac, emits gen/*.inc only
```

## Build flow

```
            ┌─────────────────────┐
            │ origin/dom6_mac     │   (Mach-O ARM64, user-supplied)
            └──────────┬──────────┘
                       │
                       v parsed by
            ┌─────────────────────┐
            │ tools/build_loader. │
            │       py            │
            └──────────┬──────────┘
                       │ emits only data
                       v
            ┌─────────────────────┐
            │ build/loader/gen/   │
            │   *.inc tables      │
            └──────────┬──────────┘
                       │
                       v #included into
            ┌─────────────────────┐
            │ src/*.c             │   (this directory)
            └──────────┬──────────┘
                       │
                       v compiled with $(CC)
            ┌─────────────────────┐
            │ build/loader/       │
            │   dom6_aarch64[.exe]│   (the loader binary)
            └─────────────────────┘
```

`gen/*.inc` files are **pure data** — lists of struct initializers,
enum bodies, address tables — emitted by `tools/build_loader.py` and
never edited directly.  `src/*.c` is **regular source code** that
changes only when the loader's *behavior* changes (vs. when the
*input binary* changes — that just triggers regen).

## OS abstraction (`loader_os.h`)

The loader's own startup operations — mmap'ing Mach-O segments,
dlopen'ing host libSDL2/libGL, registering crash + counter-dump signal
handlers, parsing the process memory map for crash diagnostics — go
through the `loader_os.h` interface.

| Call                       | POSIX (`loader_os_posix.c`) | Win32 (`loader_os_win32.c`) |
|----------------------------|-----------------------------|-----------------------------|
| `os_map_fixed`             | `mmap MAP_FIXED`            | `VirtualAlloc(MEM_RESERVE\|COMMIT)` |
| `os_map_anon_rwx`          | `mmap PROT_RWX`             | `VirtualAlloc(PAGE_EXECUTE_READWRITE)` |
| `os_lib_open/sym/error`    | `dlopen/dlsym/dlerror`      | `LoadLibrary/GetProcAddress/FormatMessage` |
| `os_install_crash_handler` | `sigaction` SEGV/BUS/ILL    | `AddVectoredExceptionHandler` |
| `os_install_dump_trigger`  | `sigaction` SIGUSR2 + atexit | console-ctrl handler + atexit |
| `os_print_memory_map`      | parse `/proc/self/maps`     | `EnumProcessModules` |
| `os_ignore_broken_pipe`    | `signal(SIGPIPE, SIG_IGN)`  | no-op (Win sockets don't raise) |
| `os_page_size`             | `sysconf(_SC_PAGESIZE)`     | `GetSystemInfo().dwPageSize` |

The `mac_*` ABI shims in `loader_shims.c` handle the *Mac binary's*
syscalls (recv, fcntl, sysctl, GCD, …).  They're organised by call,
not by OS, and conditionally compile a POSIX or Win32 implementation
per shim via `#ifdef _WIN32`.

You should almost never need to look at `gen/*.inc` content directly.
